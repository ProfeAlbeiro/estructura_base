### 📚 Explicación
> Antes de empezar a codificar, necesitamos preparar nuestro entorno de trabajo. Este proyecto utiliza **React** con **Vite** como bundler, y se conectará a un **backend Node.js + Express** con autenticación JWT. En este paso dejaremos lista la base del frontend, con todas las dependencias y configuraciones que usarán los capítulos posteriores.

### Tecnologías principales

| Tecnología           | Versión | Propósito                              |
| -------------------- | ------- | -------------------------------------- |
| **Node.js**          | v20.19+ | Entorno de ejecución JavaScript        |
| **Vite**             | 8.0.4   | Bundler rápido para aplicaciones React |
| **React**            | 19.2.4  | Biblioteca para interfaces de usuario  |
| **React Router DOM** | 7.14.0  | Enrutamiento para SPA                  |
| **JWT Decode**       | 4.0.0   | Decodificación de tokens JWT           |
| **ESLint**           | 9.39.4  | Linter para calidad de código          |

> ⚠️ **Nota sobre Node.js:** Vite 8 exige **Node ≥ 20.19** o **Node ≥ 22.12**. Con versiones anteriores (por ejemplo Node 18) el comando `npm run dev` fallará con el error *"Node.js version is too old"*. Si vienes del paso 1 con Node 18, actualízalo ahora antes de continuar.

## 2.1. Inicializar el proyecto con Vite

#### 2.1.1. Eliminar el archivo 'delete.txt'

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Vaya a la carpeta `frontend_web` del proyecto y elimine el archivo `delete.txt` (si existe).

#### 2.1.2. Abrir una terminal en VS Code

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Estando en VS Code, presionar `CTRL + SHIFT + Ñ` para abrir una terminal integrada.

#### 2.1.3. Navegar a la carpeta del frontend web


## 2.3. Configuración Clave

#### 2.3.1. Verificar el archivo package.json

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Abre `package.json` y confirma que tenga estos scripts y dependencias:

```json
{
  "name": "sis-web-mvc",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "lint": "eslint .",
    "preview": "vite preview"
  },
  "dependencies": {
    "jwt-decode": "^4.0.0",
    "react": "^19.2.4",
    "react-dom": "^19.2.4",
    "react-router-dom": "^7.14.0"
  },
  "devDependencies": {
    "@eslint/js": "^9.39.4",
    "@types/react": "^19.2.14",
    "@types/react-dom": "^19.2.3",
    "@vitejs/plugin-react": "^6.0.1",
    "eslint": "^9.39.4",
    "eslint-plugin-react-hooks": "^7.0.1",
    "eslint-plugin-react-refresh": "^0.5.2",
    "globals": "^17.4.0",
    "vite": "^8.0.4"
  }
}
```

#### 2.3.2. Configurar vite.config.js

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Modifica el archivo `vite.config.js` con este contenido:

```javascript
// vite.config.js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: {
    port: 5173,
    open: true // Abre automáticamente el navegador
  },
  define: {
    'process.env': {} // Para compatibilidad con variables de entorno
  }
})
```

**Explicación de la configuración:**

| Propiedad               | Valor       | Explicación                            |
| ----------------------- | ----------- | -------------------------------------- |
| `plugins`               | `[react()]` | Habilita el soporte de React en Vite   |
| `server.port`           | `5173`      | Puerto donde corre la aplicación       |
| `server.open`           | `true`      | Abre el navegador automáticamente      |
| `define['process.env']` | `{}`        | Evita errores con variables de entorno |

#### 2.3.3. Configurar ESLint (eslint.config.js)

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Modifica el archivo  `eslint.config.js` con este contenido:

```javascript
import js from '@eslint/js'
import globals from 'globals'
import reactHooks from 'eslint-plugin-react-hooks'
import reactRefresh from 'eslint-plugin-react-refresh'
import { defineConfig, globalIgnores } from 'eslint/config'

export default defineConfig([
  globalIgnores(['dist']),
  {
    files: ['**/*.{js,jsx}'],
    extends: [
      js.configs.recommended,
      reactHooks.configs.flat.recommended,
      reactRefresh.configs.vite,
    ],
    languageOptions: {
      ecmaVersion: 2020,
      globals: globals.browser,
      parserOptions: {
        ecmaVersion: 'latest',
        ecmaFeatures: { jsx: true },
        sourceType: 'module',
      },
    },
    rules: {
      'no-unused-vars': ['error', { varsIgnorePattern: '^[A-Z_]' }],
    },
  },
])
```

**Explicación de la configuración ESLint:**

| Sección                    | Función                                |
| -------------------------- | -------------------------------------- |
| `globalIgnores(['dist'])`  | Ignora la carpeta de build             |
| `files: ['**/*.{js,jsx}']` | Aplica a archivos .js y .jsx           |
| `extends`                  | Usa configuraciones recomendadas       |
| `ecmaVersion: 2020`        | Soporta características modernas de JS |
| `globals: globals.browser` | Reconoce variables del navegador       |
| `'no-unused-vars'`         | Previene variables sin usar            |

#### 2.3.4. Verificar/Actualizar index.html

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Abre `index.html` y confirma que tenga este contenido:

```html
<!DOCTYPE html>
```

**Elementos importantes:**

## 2.5. 🚨 Solución de problemas comunes

#### 2.5.1. Error: "Node.js version is too old"

**Problema:** La versión de Node.js es menor a v20.19.

**Solución:** Actualiza Node.js a v20.19 o superior.

```bash
# Verificar versión
node --version

# Descargar actualización desde:
# https://nodejs.org/
```

#### 2.5.2. Error: "Cannot find module 'vite'"

**Problema:** Las dependencias no se instalaron correctamente.

**Solución:** Reinstala las dependencias.

```bash
# En Windows:
rmdir /s node_modules
del package-lock.json

# En Mac/Linux:
rm -rf node_modules package-lock.json

# Luego:
npm install
```

#### 2.5.3. Error: "ESLint configuration is invalid"

**Problema:** El archivo `eslint.config.js` tiene formato incorrecto.

**Solución:** Asegúrate de usar `export default` y la sintaxis moderna.

```javascript
// ✅ Correcto (ES Modules)
export default defineConfig([...])

// ❌ Incorrecto (CommonJS)
module.exports = defineConfig([...])
```

#### 2.5.4. El puerto 5173 está ocupado

**Problema:** Otro proceso está usando el puerto 5173.

**Solución 1:** Cambia el puerto en `vite.config.js`:

```javascript
server: {
  port: 5174,  // Cambia a otro puerto
  open: true
}
```

**Solución 2:** Encontrar y cerrar el proceso que usa el puerto.

```bash
# En Windows (PowerShell):
netstat -ano | findstr :5173
taskkill /PID <PID> /F

# En Mac/Linux:
lsof -i :5173
kill -9 <PID>
```

#### 2.5.5. Error al instalar dependencias con versiones exactas

**Problema:** Conflictos de versiones entre paquetes.

**Solución:** Instala sin versiones exactas primero.

```bash
npm install react react-dom react-router-dom jwt-decode
npm install -D @vitejs/plugin-react eslint
```
