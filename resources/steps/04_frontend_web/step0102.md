## 2.1. Crear carpeta raíz del proyecto
&nbsp;

#### 2.1.1. Abrir una terminal (PowerShell o la terminal integrada de VS Code)

#### 2.1.2. Ubicarse en la carpeta donde se guardará el proyecto

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Por ejemplo, en el escritorio:

```powershell
cd $HOME\Desktop
```

#### 2.1.3. Crear la carpeta raíz `sis-web-mvc`

```powershell
mkdir sis-web-mvc
```

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Esta carpeta contendrá **dos subcarpetas hermanas** (así como en el proyecto original):

```
sis-web-mvc/
├── frontend_web/
│   └── react_node_express/    ← aquí irá React + Vite
└── backend/
    └── nodejs_express/        ← aquí irá la API Express (última parte)
```

#### 2.1.4. Crear las subcarpetas del frontend

```powershell
mkdir sis-web-mvc\frontend_web
mkdir sis-web-mvc\frontend_web\react_node_express
```

## 2.2. Abrir la carpeta en Visual Studio Code
&nbsp;

#### 2.2.1. Abrir VS Code desde la terminal en la carpeta raíz

```powershell
cd sis-web-mvc
code .
```

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Si el comando `code` no funciona, abre VS Code manualmente con **File → Open Folder** y selecciona `sis-web-mvc`.

#### 2.2.2. Verificar el explorador de archivos de VS Code

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; En el panel izquierdo (`Ctrl + Shift + E`) debes ver la estructura creada en 2.1.

## 2.3. Inicializar el proyecto con Vite
&nbsp;

#### 2.3.1. Abrir la terminal integrada de VS Code

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Presionar `` Ctrl + ` `` (Ctrl + tecla de acento grave).

#### 2.3.2. Navegar a la carpeta del frontend

```powershell
cd frontend_web\react_node_express
```

#### 2.3.3. Ejecutar el generador de Vite

```powershell
npm create vite@latest . -- --template react
```

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; El punto `.` indica que cree el proyecto **en la carpeta actual**.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Aparecerá una advertencia porque la carpeta no está vacía — **aceptar** (aún no hay archivos del proyecto).

#### 2.3.4. Instalar las dependencias base generadas por Vite

```powershell
npm install
```

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Esto creará la carpeta `node_modules/` y el archivo `package-lock.json`.

**<div align="right"><a href="#2-configuración-inicial">Volver al Menú</a></div>**

## 2.4. Instalar dependencias adicionales
&nbsp;

#### 2.4.1. Instalar `react-router-dom` para las rutas

```powershell
npm install react-router-dom
```

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Versión del proyecto original: `^7.14.0`.

#### 2.4.2. Instalar `jwt-decode` para decodificar el token JWT

```powershell
npm install jwt-decode
```

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Versión del proyecto original: `^4.0.0`.

#### 2.4.3. Verificar las dependencias instaladas

```powershell
npm list --depth=0
```

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Debes ver al menos: `react`, `react-dom`, `react-router-dom`, `jwt-decode`, `vite`.

#### 2.4.4. Revisar el archivo `package.json`

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Compara las versiones con el `package.json` del proyecto original:

| Dependencia | Versión esperada |
|---|---|
| `react` | `^19.x.x` |
| `react-dom` | `^19.x.x` |
| `react-router-dom` | `^7.x.x` |
| `jwt-decode` | `^4.x.x` |
| `vite` | `^8.x.x` |

> ⚠️ **Importante:** si tu `npm install` instaló versiones menores (por ejemplo `react@^18`), **no es un problema**. El curso funciona igual. Lo importante es que `react-router-dom` sea **v7** porque usamos su API de rutas anidadas.

## 2.5. Verificar la estructura generada
&nbsp;

#### 2.5.1. Revisar los archivos creados por Vite

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; La estructura **inicial** que genera Vite es:

```
frontend_web/react_node_express/
├── node_modules/
├── public/
├── src/
│   ├── assets/
│   ├── App.css
│   ├── App.jsx
│   ├── index.css
│   └── main.jsx
├── .gitignore
├── eslint.config.js
├── index.html
├── package-lock.json
├── package.json
├── README.md
└── vite.config.js
```

#### 2.5.2. Comparar con la estructura del proyecto original

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; En el capítulo 5 (**Estructura de Carpetas y Archivos**) iremos agregando `config/`, `controllers/`, `models/`, `hooks/`, `services/`, `styles/`, `views/` y `utils/` hasta llegar a la estructura final del proyecto `sis-web-mvc`.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; **Por ahora solo verificamos** que Vite creó correctamente la base.

#### 2.5.3. Abrir `package.json` y confirmar que el bloque `"scripts"` contiene

```json

  "dev": "vite",
  "build": "vite build",
  "lint": "eslint .",
  "preview": "vite preview"
}
```

## 2.6. Ejecutar el proyecto por primera vez
&nbsp;

#### 2.6.1. Arrancar el servidor de desarrollo

```powershell
npm run dev
```

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; La terminal mostrará algo como:

```
VITE v8.0.4  ready in 512 ms

➜  Local:   http://localhost:5173/
➜  Network: http://172.24.16.x:5173/
```

#### 2.6.2. Abrir la aplicación en el navegador

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Abrir http://localhost:5173 y verificar que aparece el logo de **React** girando y el botón **"Count is 0"**.

#### 2.6.3. Probar el Hot Module Replacement (HMR)

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Abrir `src/App.jsx` y cambiar cualquier texto, por ejemplo:

```jsx
<h1>Vite + React</h1>
```

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Reemplazarlo por:

```jsx
<h1>Mi Sistema de Información Web</h1>
```

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Al guardar (`Ctrl + S`), el navegador debe actualizarse **sin recargar** la página completa. Eso es **HMR**.

#### 2.6.4. Detener el servidor

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; En la terminal integrada presionar `Ctrl + C` y confirmar con `S`.

📌 **Notas sobre este paso:**

1. **El punto `.` en `npm create vite@latest .`** es clave — así creamos el proyecto **dentro** de la carpeta `react_node_express` y no dentro de una subcarpeta extra. Esto es lo que suele descuadrar la estructura en clase.
2. **`-- --template react`** lleva **dos guiones dobles**: el primero pasa argumentos a `npm create`, el segundo le dice a `vite` la plantilla. Si solo pones `-template` falla.
3. **Dejamos `npm install` dos veces separadas** (`npm install` y luego `npm install react-router-dom jwt-decode`) porque así los estudiantes **ven** que se agregan nuevas dependencias — pedagógicamente es más claro que meter todo en un solo `npm install`.
4. **No tocamos `vite.config.js`** todavía. En el paso 3 (Iniciar el Proyecto) lo ajustamos con `port: 5173` y `open: true`, como en tu proyecto original.
5. **Los `Network`** que muestra Vite al arrancar (`172.24.16.x`) son justamente los que necesitaremos en el Capítulo 10 cuando el backend Express haga `CORS`. Los guardamos mentalmente.
6. **Nombre del archivo del próximo paso**: `step03.md` para continuar la convención.

Cuando ya tengas todo corriendo y hayas probado el HMR escribiendo **"siguiente"**, te entrego el **Paso 3 — Iniciar el Proyecto** (que incluye ajustar `vite.config.js`, `index.html` y limpiar el boilerplate de Vite). 🚀
