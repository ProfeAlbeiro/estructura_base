## 1.1. Instalar Visual Studio Code
&nbsp;

#### 1.1.1. [Descargar Visual Studio Code](https://code.visualstudio.com/download)

#### 1.1.2. Instalar Visual Studio Code

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Ejecutar el instalador y aceptar todas las opciones por defecto.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Marcar la casilla **"Add to PATH"** (viene marcada por defecto).

#### 1.1.3. Abrir Visual Studio Code

#### 1.1.4. Instalar extensiones en Visual Studio Code

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Abrir el panel de extensiones con `Ctrl + Shift + X`.

| Extensión | Para qué |
|---|---|
| **ES7+ React/Redux/React-Native snippets** | Atajos como `rafce` (crea componente funcional) |
| **Prettier - Code formatter** | Formateo automático |
| **ESLint** | Mostrar errores de lint mientras escribes |
| **Thunder Client** (opcional) | Probar APIs sin salir de VS Code |
| **Spanish Language Pack** | Si prefieres la interfaz en español |

#### 1.1.5. Cerrar Visual Studio Code

## 1.2. Instalar Node.js
&nbsp;

#### 1.2.1. [Descargar Node.js](https://nodejs.org/es/)

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Descargar la versión **LTS** (Long Term Support).

> ⚠️ **Importante:** el proyecto original usa `react@^19.2.4` y `vite@^8.0.4`. Vite 8 requiere **Node ≥ 20.19** o **Node ≥ 22.12**. Con versiones anteriores Vite fallará al arrancar.

#### 1.2.2. Instalar Node.js

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Ejecutar el instalador y aceptar todas las opciones por defecto.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Asegurarse de que la opción **"Add to PATH"** esté marcada.

## 1.3. Modificar Directivas en PowerShell
&nbsp;

#### 1.3.1. Abrir PowerShell

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Presionar `Win + X` y elegir **Windows PowerShell** o **Terminal**.

#### 1.3.2. Verificar restricciones del 'npm'

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Ejecutar el siguiente comando en PowerShell para verificar la política de ejecución:

```powershell
Get-ExecutionPolicy
```
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ● &nbsp; Si aparece 'Restricted', hay que cambiarla a 'Unrestricted' de la siguiente forma:

```powershell
Set-ExecutionPolicy -Scope CurrentUser
```
&nbsp;&nbsp;&nbsp; cmdlet Set-ExecutionPolicy en la posición 1 de la canalización de comandos<br>
&nbsp;&nbsp;&nbsp; Proporcione valores para los parámetros siguientes:<br>
&nbsp;&nbsp;&nbsp; ExecutionPolicy: <ins>**Unrestricted**</ins><br>

#### 1.3.3. Verificar versiones 'node' y 'npm':

```bash
node --version # Debe mostrar v20.19.x o superior
```
```bash
npm --version # Debe mostrar v10.x.x o superior
```
